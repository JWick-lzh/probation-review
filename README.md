# 转正述职：三种风格 PPT 与三种网页

林灶辉 · 战略经营部 AI 创新助理 · 2026-10-27 转正述职材料

**在线查看：** https://jwick-lzh.github.io/probation-review/

## 里面有什么

同一份述职内容，做成三套 PPT 和三个网页。

| 类型 | 名称 | 风格参照 | 怎么看 |
|---|---|---|---|
| PPT | 证据报告版 | Our World in Data：每页标题是一句能判断真假的结论，左图右注，图下一行来源 | 放映 / PDF / 可编辑 PPTX |
| PPT | 大字报版 | 新瑞士风格：白底加 logo 蓝，一页一个大数字，蓝色只给做到的部分 | 放映 / PDF / 可编辑 PPTX |
| PPT | 几何版 | 田中一光：米纸底四色平涂，几何形的面积和填色对应真实数据，竖排宋体标题 | 放映 / PDF / 可编辑 PPTX |
| 网页 | 滚动叙事 | The Pudding：正文往下读，右边的图跟着段落变化 | 单文件网页 |
| 网页 | 数据肖像看板 | Giorgia Lupi：5 朵花代表 5 个目标，花瓣长度是完成度 | 单文件网页 |
| 网页 | 年度信 + 产品阵列 | Stripe 年度信 + Apple 产品页：首屏是一封信，工具点开是大卡片 | 单文件网页 |

三套 PPT 每套 29 页，页序相同。

│   ├── 转正述职-证据报告版-29页.pdf
│   └── 转正述职-证据报告版-29页-可编辑.pptx
├── ppt-大字报/        结构同上
├── ppt-几何/          结构同上
└── 网页/

## 怎么看

- **在线：** 打开上面的链接，进入总览页后点「放映」「PDF」「可编辑 PPTX」或网页卡片。
- **放映：** 方向键翻页，Esc 回概览。
- **现场投屏：** 建议用 PDF，字体已嵌进文件，断网也不变样。
- **本地：** 在仓库目录运行 `python3 -m http.server 8000`，再打开 http://localhost:8000/ ，进入总览页后点「放映」「PDF」「可编辑 PPTX」或网页卡片。

## 说明

- 内容来自飞书述职报告，数据截至 2026-10-26。
- 「后三个月」部分全部是计划，不是已完成。
- 可编辑 PPTX 由 HTML 转出：每页一张底图，上面的文字是可编辑文本框；图表和示意图里的文字在底图上，不能直接改。
- 放映页的字体从 Google Fonts 加载，加载不到时用系统自带的中文字体显示。
